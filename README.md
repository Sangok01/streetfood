# 오늘도 분식집! — 내 가게는 내가 키운다

비주얼 노벨, 경영 시뮬레이션, RPG를 합친 분식집 인생경영 웹게임입니다.
작은 포장마차에서 시작해 분식집 → 한식당 → 세계 음식점 → K-Food 브랜드까지 가게를 키웁니다.

## 실행 방법
- `index.html` 파일 하나로 실행됩니다. 설치나 로그인이 필요 없습니다.
- 더블클릭하면 크롬·엣지·웨일에서 바로 열립니다.
- **GitHub Pages로 링크 만들기**
  1. GitHub에 새 저장소(Public)를 만들고 `index.html`을 올립니다.
  2. Settings → Pages → Branch `main` / `(root)` → Save를 누릅니다.
  3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 접속합니다.
- 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.
  - 저장 슬롯 3개와 자동 저장 백업이 있습니다.
  - 불러오기는 타이틀 화면이나 게임 안 💾 버튼에서 합니다.

## 파일 구조
단일 HTML 안에 영역별 주석으로 나뉘어 있습니다. 원본 소스는 `src/` 폴더에 있습니다.

| 파일 | 역할 |
|---|---|
| `data_foods.js` | 음식 52종, 숙련도 단계, 특수 재료 |
| `data_world.js` | 요리 레벨, 평판, 가게 레벨·브랜드, 손님 13유형, 인물, 직원 8명, 인테리어 24종, 홍보, 업적 26개, 엔딩 10개, 저녁 행동 |
| `data_events.js` | 랜덤·황당·손님·사회 이슈·계절 이벤트 (선택지형 비주얼 노벨 사건) |
| `data_story.js` | 스토리 이벤트, 직원 이벤트, 단골 대화, 특별 퀘스트 |
| `core.js` | 상태, 저장(손상 데이터 복구), 효과 적용, 연구 규칙 |
| `vn.js` | 비주얼 노벨 재생기 (배경·인물·대화창·선택지·미니게임) |
| `game.js` | 하루 흐름, 영업 시뮬레이션, 결산, 저녁 행동, 엔딩 판정 |
| `screens.js` | 모든 화면 (타이틀·허브·음식 트리·가게·직원·인테리어·스토리·경영·준비·영업·결산·엔딩) |
| `art_bg.js` | 코드로 그린 배경과 가게 일러스트 (가게 레벨·인테리어에 따라 바뀜) |
| `IMG` | 붙임 캐릭터 이미지에서 잘라 낸 인물 34명, 로고, 일러스트 |

## 게임 시스템
- **하루**
  - 흐름: ☀ 아침 사건 → 🧺 영업 준비 → 🔥 영업 → 🧾 결산 → 🌙 저녁 행동 → 🛏 다음 날
  - 영업 준비에서 메뉴·재료량·가격 정책을 정합니다.
  - 저녁 행동은 하루 행동력 5, 체력 10 안에서 합니다.
- **영업**
  - 손님이 줄을 서고, 주문표를 누르면 사장님이 직접 조리합니다. 더 빠르고 품질도 오릅니다.
  - 오래 기다린 손님은 떠납니다.
- **품질**
  - 등급: 실패 · 보통 · 맛있음 · 아주 맛있음 · 최고급
  - 등급에 따라 판매가, 만족도, 경험치가 달라집니다.
- **음식별 숙련도**
  - 단계: Lv.5 맛 +10% → Lv.10 원가 -5% → Lv.15 손이 빨라짐 → Lv.20 시그니처(대표 메뉴 지정) → Lv.30 특별 레시피 → Lv.40 달인 → Lv.50 전설
- **음식 트리**
  - 7개 트리(분식·김밥·면·한식·찌개·세계·K-Food)가 RPG 스킬트리처럼 이어집니다.
  - 부모 음식의 숙련도, 요리 레벨, 연구비·연구일, 특수 재료나 스토리 조건이 맞아야 해금됩니다.
- **손님·단골**
  - 손님 13유형은 취향·예산·인내심이 서로 다릅니다.
  - 이름 있는 단골 인물이 직접 찾아오며, 단골 레벨은 1~5단계입니다.
- **직원**
  - 민수·지영·서준·유나·다온·현우·지호·하린
  - 능력치·성격·주급이 각각 다릅니다. 친밀도가 오르면 특별 이벤트가 생깁니다.
- **가게 확장**
  - Lv.1 포장마차에서 Lv.10 프랜차이즈까지 성장합니다.
  - 한식당·세계 음식점·K-Food 단계마다 조건이 있습니다.
- **돈**
  - 들어오는 돈: 매출, 배달, 2호점·로열티
  - 나가는 돈: 재료비, 임대료, 공과금, 주급(7일마다), 인테리어, 연구비
- **엔딩 10개**
  - 100일째 밤, 선택과 성과에 따라 엔딩이 갈립니다.
  - 본 엔딩은 엔딩 갤러리에 모입니다.
  - 엔딩을 본 뒤에도 자유 모드로 계속 영업할 수 있습니다.

## 콘텐츠 추가 방법
핵심 코드는 고치지 않고 데이터 배열에 한 줄만 추가하면 됩니다.

- **새 음식**
  - `data_foods.js`에 `F('id','이름','아이콘','카테고리','트리',요리Lv,재료비,판매가,조리초,난이도,인기,만족,경험치,{par:[['부모id',숙련]], rc:[연구비,일수], tags:[...]})`를 추가합니다.
  - 음식 트리 화면에 자동으로 배치됩니다.
- **새 이벤트**
  - `data_events.js`에 `EV('id',{title, tag, when, cond}, [대본])`을 추가합니다.
  - 선택지 효과(fx)에는 `money`, `rep`, `reg`, `aff`, `buff`, `unlock`, `short`, `flag` 등을 씁니다.
- **새 스토리**
  - `data_story.js`에 `ST('id',{when, cond, pri}, [대본])`을 추가합니다.
- **새 인테리어·업적·엔딩**
  - `data_world.js`의 `INTERIORS`, `ACHIEVEMENTS`, `ENDINGS` 배열에 추가합니다.
